# Go live — The Long Run on Cloudflare Workers

Target URL: **`longrun.vanvelzen.dev`**. Data lives in Cloudflare D1 (`thelongrun`, WEUR).

## New machine / clone

```bash
npm install
npm run login                 # same Cloudflare account
npm run d1:apply:local        # empty local SQLite
npm run d1:pull               # optional: copy remote D1 into local
npm run dev                   # local D1 under .wrangler/state (gitignored)
```

Production deploys from a push to `main` (Cloudflare Workers Builds). Do not run
`wrangler deploy` from this machine.

D1 schema changes are not part of that build — apply them with `npm run d1:apply:remote`
before or after the Worker rolls out.

Optional weather defaults: Worker → Settings → Variables (`DEFAULT_LAT` / `DEFAULT_LON`).

## Custom domain

Already on `longrun.vanvelzen.dev` (zone `vanvelzen.dev` is on Cloudflare).

## Lock it to just you (Cloudflare Access)

Dashboard → **Zero Trust → Access → Applications** → self-hosted app for `longrun.vanvelzen.dev`,
policy **Allow** your email.

## After a main push

- **Log run** / **Import GPX** write to D1.
- If an old Worker secret `DATABASE_URL` is still set, delete it (Settings → Variables and Secrets).
- The Neon project can be deleted in the Neon dashboard; the app no longer uses it.

## Notes

- `.env` / `.dev.vars` are gitignored. There is no database URL anymore.
- `src/routeTree.gen.ts` is generated by the build and is gitignored.
- `data/*.md` in the repo is historical backup only; the running app reads D1.
